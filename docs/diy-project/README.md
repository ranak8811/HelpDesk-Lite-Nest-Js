# EventPulse-Lite: নিজে প্রজেক্ট তৈরির সম্পূর্ণ হ্যান্ডবুক

অভিনন্দন! আপনি যদি HelpDesk-Lite প্রজেক্টের প্রতিটি কনসেপ্ট বুঝে থাকেন, তবে এবার সময় এসেছে নিজের মেধা ও চিন্তাশক্তি খাটিয়ে স্ক্র্যাচ থেকে একটি নতুন সিস্টেম তৈরি করার। 

প্রোগ্রামিং শেখার শ্রেষ্ঠ নিয়ম হলো: **টিউটোরিয়াল দেখে কোড করা ৩০%, আর নিজে নিজে একটি সিস্টেম ডিজাইন করে কোড লেখা ৭০%।**

আপনার জন্য যে প্রজেক্টটি ডিজাইন করা হয়েছে তার নাম: **`EventPulse-Lite`** (একটি আধুনিক টেক ইভেন্ট ও সিট বুকিং REST API)।

> 🛑 **এই গাইডের নিয়ম:** এই ডকুমেন্টগুলোতে আপনাকে কোনো তৈরি কোড (Copy-Paste Code) দেওয়া হয়নি! এখানে একজন সিনিয়র আর্কিটেক্টের মতো আপনাকে **প্রোডাক্টের রিকোয়ারমেন্ট, আর্কিটেকচারাল চিন্তাভাবনা, বিজনেস রুলস এবং ধাপে ধাপে কাজ সম্পন্ন করার রোডম্যাপ** দেওয়া হয়েছে। কোড লিখবেন আপনি নিজে!
